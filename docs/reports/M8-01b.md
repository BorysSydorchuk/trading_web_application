# M8-01b: Saved digests follow exclude / include (tier L: migration)

Branch `m8/digest-recompute`, commits `fb76ef6` (feature), `1adc1f4`, `818780d` (review tests). Merge `71e599b` (range `7e09bf7..71e599b`).

## What was built
- «Не враховувати у статистиці» / «Повернути у статистику» now recompute, in the same request, the saved weekly and monthly digests whose period contains the trade's close date (Brussels). One digest row holds the combined and per-account blocks, so both are updated. Numbers only: review texts and the AI summary text stay; no digest is created; an open trade touches none.
- A saved AI summary is not re-run. It gets the badge «Підсумок застарів: дані змінено <дата>» (new column `digests.ai_summary_stale_at`) until «Оновити підсумок».
- The exclusion dialog note now says the digests are recomputed automatically; the digest pages refresh after the action.
- If a recompute fails (e.g. mixed account currencies, broken config), the exclusion is rejected with the error and nothing changes.
