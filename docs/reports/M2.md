## How to run

1. Run `start.bat` (unchanged from M1).
2. **AI:** put `ANTHROPIC_API_KEY=…` in `.env` and restart the app.
   - Optional settings: `ANTHROPIC_MODEL_EXTRACTION`, `ANTHROPIC_MODEL_FALLBACK`, `ANTHROPIC_EFFORT`.
   - The `.env.example` AI block was edited by Borys and is not yet committed.
3. **Describe a trade:** open "Потрібен опис", then "Описати". Type the description, click "Заповнити з тексту", check the fields, add a TradingView link, then click "Зберегти".
4. **Live AI eval:** `make ai-eval` or `make ai-eval AI_MODEL=claude-opus-5-5`.

## Known issues

- **First call after a schema change:** after a change to `journal_fields.yaml`, or when the API drops its cached copy of the schema, the first call takes about 25 s against a 28 s limit. A slow network can make that one call time out; a retry is then fast. The fallback model may also need about 25 s on its own first use. A warm-up call at startup would hide this (BACKLOG, PM decision).
- **TradingView thumbnail:** not confirmed with a real snapshot. QA's fake snapshot id got HTTP 403, so only the plain-link fallback has been seen.
- **Abandoned AI calls:** a call that times out may still be billed, but its late tokens are not in `ai_usage.jsonl`, so the month total can be slightly low.
- **Spaced ranges:** a range with spaces ("4 - 5") still passes the number guard as either end (BACKLOG).
- **Ratings in words:** only 1–5 are recognised, and only the listed forms.
- **New required field:** when a required field is added to the YAML, existing `complete` trades stay `complete` (no automatic downgrade); the field shows in their `missing_required`.
- **Rule-violation details:** only the Ukrainian rule name is shown. The amount by which a limit was exceeded is not shown yet (BACKLOG).
- **Client Program Files check:** it is simpler than the server's and differs on rare inputs; the server decides (BACKLOG).
- **Frontend tests:** components are not tested yet. That would need `jsdom` and `@testing-library/react` (BACKLOG, new dependencies).

## Assumptions made (all in docs/DECISIONS.md)

- **Journal save:** `PUT …/journal` fully replaces the keys currently in the YAML. Extra keys that are no longer in the YAML are kept. Empty values are `null`, and `journal` does not include links fields.
- **Rule violations:** an "auto" violation means the auto rows at request time. A violation key that is already auto never becomes a user violation.
- **Broken config files:** a broken `journal_fields.yaml` gives `config_error` on GET, PUT and PATCH, and nothing is saved, not even the SL. A broken `rules.yaml` still saves; only the rule recompute is skipped.
- **Model settings:** `ANTHROPIC_MODEL_EXTRACTION` / `_SUMMARY` / `_FALLBACK` / `_EFFORT`. The summary model is for M6 only.
- **Time budget:** the primary attempt has 28 s with no SDK retries. The fallback runs only if at least 5 s remain, with a limit of min(25 s, time left). The whole call stays within 30 s.
- **No prompt caching yet:** calls are minutes apart, and cache writes cost 1.25×.
- **Pricing:** cost is calculated from `config/ai_pricing.yaml` (Sonnet 2/10, Opus 4/20 USD per million tokens).
