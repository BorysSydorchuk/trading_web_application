# M8-09 — Exit reason from MT5 (tier L)

Branch `m8/exit-reason`, commits `e73e698` (feature) and `9a74f18` (review fixes), merged `eb6e690`.

## What was built
- Sync keeps each closing deal's MT5 DEAL_REASON as the mapped key (`trade_exit_deals.reason`, already existed) plus the raw code (`trade_exit_deals.reason_code`, new). A missing reason is now NULL end to end (it used to default to 0 = client).
- `trades.exit_reason` is prefilled from the final closing deal: SL -> «SL», TP -> «TP», stop-out -> «стоп-аут» (new option). Manual closes (client/mobile/web/expert) and any other reported reason stay empty for the owner.
- Fallback only when MT5 reported no reason: final deal price within 1 tick of the initial SL / TP. Both or neither -> empty.
- Partial closes: the final deal decides; per-deal reasons are in the trade details table «Закриття (exit deals)».
- `trades.exit_reason_source` (mt5_reason / price_match / owner): a journal save that changes or clears the value sets `owner`; the sync never touches owner values or values from before M8-09. The prefill is a guarded UPDATE, so an owner save made concurrently always wins. A prefill is never cleared by a later sync.
- Describe form: «MT5» badge on a prefilled exit reason (the hint names the source); it disappears once the owner changes the field. AI extraction never replaces it.
- Backfill tool `python -m app.tools.backfill_exit_reason [--apply]` (dry run by default).
- API: `TradeDetail.exit_reason_source`, `exit_deals[].reason_code` (docs/api.md "M8-09").
