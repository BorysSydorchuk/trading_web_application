## How to run

See `README.md`. Short version on Windows: install Python 3.12, Node LTS, Docker Desktop, uv, git (optional: GNU make), then in the repo folder run `.\start.bat` (PowerShell or cmd) or double-click `start.bat`. The browser opens at http://127.0.0.1:5173. Stop with Ctrl+C.

## Assumptions made (all in docs/DECISIONS.md)

- Docker Postgres is the default; native Postgres works by editing `DATABASE_URL` (README section).
- Open MT5 positions will be stored as trades with status `open` (close time empty); the inbox only shows `needs_sl` / `needs_description` / `draft`.
- Bias alignment is stored as computed daily/weekly/monthly values plus a manual override with reason; the override wins.
- Trade `weekday`/`hour` and bias `period_date` are Brussels time; everything else is UTC.
- Accounts with trades cannot be deleted, only archived.
- Decimal values travel in the API as strings.
- Tools installed on the laptop for development: uv (pip) and GNU make (winget).
