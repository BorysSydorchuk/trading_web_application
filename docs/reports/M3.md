## What was built
- **Hold-to-record** on the Describe screen (`features/voice/VoiceRecorder`, reusable for M4 bias): pointer or Space/Enter, < 1 s discarded with a hint, 10 min auto-stop, mic denied / no mic / unsupported messages, text input always works.
- **"Завантажити аудіо"** button in the same component: .ogg / .opus / .m4a / .mp3 / .wav / .webm, ≤ 25 MB, format by file extension (Telegram .ogg works), Ukrainian errors for wrong format / too large.
- **Upload + queue**: `POST /api/trades/{id}/audio` (raw body), files in `data/audio/YYYY/MM/`, never deleted. The worker transcribes one note at a time with local faster-whisper (`small`, int8, CPU), progress shown in the UI, failed upload kept with retry/delete, failed transcription shows a Ukrainian error, keeps the audio and can be retried.
- **Whisper defaults** (PM 2026-11-05): beam 1, VAD on, condition_on_previous_text on, temperatures 0.0,0.4, threads = physical cores; all overridable in `.env`. `make whisper-bench` for measurements.
- **Term normalization** `config/transcript_glossary.yaml`: deterministic replacements before the transcript reaches the text box (ФВГ → FVG, FVH1 → FVG H1, ІФВГ/ИФВГ → IFVG, Cyrillic Н1/Н4/М5 → H1/H4/M5, plus ФТА, МТ5, М1/М15/М30 approved by Borys).
- **Transcript → text → extraction**: the normalized transcript is appended to the editable description, then "Заповнити з тексту" runs the M2 extraction.
- **Number words** moved to `config/extraction.yaml`; ambiguous numbers ("4 або 5") left empty.
- **AI warm-up** in the worker when the extraction schema changes (cause of the ~25 s first call: structured-output grammar compile).
- **New required fields** apply only to trades closed after the change (`journal_field_requirements`); Journal filter "Неповні за новими полями"; grey note on Describe.
- **AI key check** at startup (no tokens): status bar chip "AI: ключ недійсний" / "ключ не задано" / "немає звʼязку", Settings → ШІ state + "Перевірити ключ".
- **Encoding hardening** (bug M3-15): config read as UTF-8 (BOM tolerated), garbled config refused with a Ukrainian error naming the file, AST test that fails on any file I/O without an explicit encoding, `scripts/qa_live_check.py` for the live check.

## Assumptions made
- Transcript is normalized in the worker and stored normalized (audio kept, so the raw text can be regenerated); typed text is not normalized.
- 404 / 429 from the key check count as "key accepted" (`ok`), only 401/403 as `invalid_key`.
- An invalid AI key does not turn the server/DB indicator red; it shows a separate chip.
- `required_since` first fill stamps 1970 for the fields required at that moment, later changes stamp now(); toggling `required` off and on again resets the date.
