# Підключення MT5 до журналу (Windows)

Журнал лише **читає** дані з MetaTrader 5: угоди, ордери, відкриті позиції, баланс і
специфікації символів. Він ніколи не відкриває, не змінює і не закриває позиції. Для
підключення використовується **інвесторський пароль** (тільки читання), тому торгувати
через нього неможливо навіть теоретично.

Для кожного рахунку потрібен **окремий портативний термінал** (окрема папка). Пакет
MetaTrader5 для Python працює з одним терміналом за раз, тому фоновий процес по черзі
підключається до кожного рахунку, читає дані і відключається.

---

## 1. Створити портативну копію термінала

1. Закрийте всі запущені термінали MT5.
2. Знайдіть папку, куди встановлено термінал FundedNext, наприклад
   `C:\Program Files\FundedNext MT5 Terminal` (там лежить `terminal64.exe`).
   Якщо не впевнені: правий клік на ярлику MT5 → «Розташування файлу».
3. Створіть папку для рахунку, наприклад `D:\MT5\fn-stellar-p1\`
   (одна папка = один рахунок; назва довільна, краще без кирилиці).
4. Скопіюйте **весь вміст** папки встановлення в `D:\MT5\fn-stellar-p1\`.

## 2. Перший запуск у портативному режимі

1. У папці `D:\MT5\fn-stellar-p1\` правий клік на `terminal64.exe` → «Надіслати» →
   «Робочий стіл (створити ярлик)».
2. Правий клік на новому ярлику → «Властивості» → поле «Об'єкт». Додайте в кінці
   через пробіл `/portable`, щоб вийшло:
   `"D:\MT5\fn-stellar-p1\terminal64.exe" /portable`
   Перейменуйте ярлик, наприклад «MT5 FN P1 (журнал)».
3. Запустіть термінал **через цей ярлик**. У режимі `/portable` усі налаштування
   й історія зберігаються всередині цієї папки, а не в `AppData`, тож термінали різних
   рахунків не заважають один одному.

## 3. Увійти з інвесторським паролем

1. У терміналі: «Файл» → «Підключитися до торгового рахунку».
2. Логін — номер рахунку, пароль — **інвесторський** (Investor password) з кабінету
   FundedNext, сервер — як у листі FundedNext (наприклад `FundedNext-Server`).
3. Увімкніть «Зберегти пароль».
4. «Алгоритмічна торгівля» **не потрібна** — не вмикайте її.
5. Перевірка: внизу у вкладці «Історія» видно ваші угоди (правий клік → «Весь період»),
   у правому нижньому куті є з'єднання (немає напису «Немає з'єднання»).
6. Термінал можна закрити: журнал сам запускає його у фоні, коли треба.

## 4. Налаштувати рахунок у журналі

1. Відкрийте журнал → **Налаштування → Рахунки** → створіть або відредагуйте рахунок.
2. **Логін** і **сервер** — точно як у терміналі (сервер — до символу, з урахуванням дефісів).
3. **Шлях до термінала**: `D:\MT5\fn-stellar-p1\terminal64.exe`.
4. Збережіть. Біля рахунку буде показано назву ключа для пароля, наприклад
   `MT5_PASSWORD_12345678`.

## 5. Додати пароль у `.env`

1. Відкрийте файл `.env` у корені проєкту (`D:\Trading Scripts\WEB_application\.env`)
   у Блокноті.
2. Додайте рядок (логін — ваш номер рахунку, пароль — інвесторський):

   ```
   MT5_PASSWORD_12345678=ваш_інвесторський_пароль
   ```

   Без лапок і пробілів навколо `=`. Якщо пароль містить `#` або пробіли, візьміть його
   в одинарні лапки: `MT5_PASSWORD_12345678='pa ss#word'`.
3. Збережіть файл. `.env` не потрапляє в git, пароль ніде не логується і не
   показується в інтерфейсі.

## 6. Перезапустити і перевірити

1. Перезапустіть застосунок (`stop.bat`, потім `start.bat`).
2. У рядку стану внизу з'явиться стан синхронізації рахунку. Протягом хвилини (у
   торгові години) або 15 хвилин (поза ними) він має стати «OK».
3. Угоди з'являться в Журналі, нові закриті угоди — у «Потрібен опис».

## Демо-рахунок для тестування

Перші перевірки робіть **тільки на демо-рахунку**, ніколи не на челендж-рахунку.

1. Створіть **окрему** папку, наприклад `D:\MT5\demo\`, і скопіюйте туди термінал (крок 1).
2. Запустіть з `/portable` (крок 2), «Файл» → «Відкрити рахунок» → демо-рахунок
   (безкоштовно, сервер FundedNext-Demo або демо-сервер брокера).
3. Зробіть кілька угод на демо (часткове закриття, угода без SL тощо) — саме вручну в
   терміналі; журнал нічого не відкриває.
4. Додайте демо-рахунок у журнал і його пароль у `.env`, як у кроках 4–5.

Запис фікстури з демо для тестів (тільки читання, пароль у файл не записується):

```
cd backend
uv run python -m app.mt5.record --terminal "D:\MT5\demo\terminal64.exe" --login 12345678 --server "FundedNext-Demo" --days 14 --anonymize --out tests\fixtures\mt5\recorded_demo.json
```

## Якщо щось не працює

Код помилки видно в рядку стану та в `logs\worker.log`.

| Код | Що означає | Що робити |
|---|---|---|
| `password_missing` | У `.env` немає `MT5_PASSWORD_<логін>` або він порожній | Додайте рядок (крок 5), перевірте номер логіна в назві ключа |
| `terminal_not_found` | За вказаним шляхом немає `terminal64.exe` | Перевірте шлях у Налаштуваннях (повний шлях до `terminal64.exe`) |
| `terminal_start_failed` | Термінал не запустився або не відповів | Запустіть ярлик вручну — чи відкривається? Не встановлено оновлення, що чекає перезапуску? |
| `login_failed` | Невірний пароль/сервер, або термінал увійшов в інший рахунок | Перевірте інвесторський пароль і точну назву сервера; увійдіть вручну через ярлик |
| `timeout` | Термінал довго не відповідав | Зазвичай минає саме; якщо повторюється — перезапустіть термінал і застосунок |
| `mt5_error` | Інша помилка MT5 | Деталі в `logs\worker.log` |

**Термінал уже запущений не в портативному режимі.** Якщо ця сама папка відкрита звичайним
ярликом (без `/portable`), він використовує інші налаштування й інший обліковий запис.
Закрийте його і запускайте лише ярликом з `/portable`.

**Два рахунки в одній папці.** Не використовуйте одну папку для двох рахунків: при кожній
синхронізації термінал перелогінювався б з одного рахунку на інший. Одна папка = один
рахунок. Для торгівлі можна й далі користуватися звичайним встановленим терміналом —
він окремий від цих копій.

**Після оновлення MT5.** Портативні копії оновлюються самі при запуску. Якщо після
оновлення з'явився `terminal_start_failed`, один раз запустіть ярлик вручну, дочекайтеся
оновлення і закрийте.
